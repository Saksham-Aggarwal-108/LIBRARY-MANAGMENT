# Product Requirements Document (PRD)

## Project Title
Library Management System

## Project Overview
The Library Management System is a modern, responsive web application developed as a semester-long academic project. Phase 1 focuses on semantic HTML5, CSS3, responsive web design, accessibility, and minimal JavaScript.

## Target Users
* Students
* Librarians (Admin)
* Visitors

## Phase 1 Scope
* Frontend only, no database/auth server.
* Validation using JavaScript.
* Logout redirects to Home.

## Pages Needed
* `index.html` (Home)
* `about.html` (About)
* `books.html` (Books Listing)
* `book-details.html` (Book Detail Page)
* `contact.html` (Contact form + verification)
* `login.html` (Login page)
* `register.html` (Registration page)
