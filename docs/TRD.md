# Technical Requirements Document (TRD)

## Technology Stack (Current Phase)
* HTML5
* CSS3
* JavaScript (Vanilla)

## Project Folder Structure
As specified in the PRD, we will maintain the following folder structure:
* root: index.html, about.html, books.html, book-details.html, contact.html, login.html, register.html
* assets/css/: variables.css, style.css, responsive.css, animations.css
* assets/js/: main.js, validation.js, books.js
* assets/images/: logo/, hero/, books/, icons/, team/
* components/: navbar.html, footer.html
* data/: books.json
* docs/: PRD.md, TRD.md
* README.md

## Responsive Breakpoints
* Mobile: ≤576px
* Tablet: 577–992px
* Desktop: 993px+
* Large Desktop: 1200px+
